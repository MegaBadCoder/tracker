# MCP для управления спринтами

**Status:** done
**Branch:** feat/agile-board
**Worktree:** /Users/v/projects/Alfy/.worktrees/feat-agile-board
**Goal:** MCP-клиент под API-токеном управляет жизненным циклом спринта и переносит истории/задачи через существующий REST API.

## Решение
`registerSprintTools` добавляет восемь инструментов: list/create/update/start/complete/delete_sprint, list_project_groups, move_story_to_sprint. У задач доступны groupId/sprintId и фильтр sprint_id; проекты возвращают type, создание принимает type=agile. Даты и цель переноса задаются явно, удаление требует confirm=true. Команды используют существующие серверные проверки и транзакции.

Контроллеры спринтов и групп подключены к существующему JwtOrApiTokenGuard: прежний JWT-only guard возвращал 401 для MCP-токена. Владелец проекта по-прежнему проверяется сервисами.

## Проверка
- RED: инструменты отсутствовали в MCP; create_task терял groupId/sprintId; фильтр sprint_id игнорировался; API-токен получал 401 на создании спринта.
- GREEN: 152 MCP-теста, включая 20 проверок через реальный SDK и InMemoryTransport; семь HTTP e2e с проверкой API-токена, JWT, неверного токена и чужого проекта. Сборки MCP/backend и npm run lint MCP прошли.
- Живой stdio MCP → localhost:3102/api под Dev 424242: создание Agile-проекта, список/изменение/запуск/завершение спринтов, перенос истории, наследование спринта новой задачей, фильтр задач и удаление специально созданных спринтов прошли. Временный API-токен отозван в finally; токен не сохранялся в исходниках и логах.
- Живой HTTP MCP на localhost:3103/mcp: реальный SDK подтвердил регистрацию восьми инструментов и авторизованное чтение спринтов Dev. Сервер оставлен запущенным с локальным API localhost:3102/api.
