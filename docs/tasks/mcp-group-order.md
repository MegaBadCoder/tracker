**Goal:** Агент через MCP переставляет эпики проекта и истории внутри эпика; последующее чтение дерева возвращает сохранённый порядок, используемый доской. Useless if: меняется только ответ MCP; перемещаются родители или задачи; смешиваются чужие проекты или истории разных эпиков.

## Context
- main ea4e243 содержит проверенный атомарный PATCH /projects/:projectId/groups/reorder, используемый стрелками доски.
- MCP умеет читать и изменять группы, но не публикует перестановку.

## Design
Один инструмент reorder_project_groups(projectId, orderedIds), тонкая обёртка над существующим REST. Список идёт сверху вниз; все UUID принадлежат одному уровню одного проекта. Частичный список поднимает указанных соседей наверх, остальных сохраняет следом в прежнем порядке. Полный список позволяет задать точную перестановку. Возвращать {ok:true} только после успешной записи. Альтернативы — отдельные инструменты для эпиков/историй или команды вверх/вниз — добавляют дублирование и чтения; общий список соответствует существующему API. TDD: yes.

### Invariants
- IV1 — Один вызов MCP делает один PATCH; projectId не попадает в body.
- IV2 — Пустой список, неверные UUID и дубликаты отклоняются до REST; ограничения уровня и доступа остаются на бэкенде.
- IV3 — Ошибки REST видны агенту, успешная команда не меняет связи групп/задач.
- IV4 — Новый порядок сохраняется и читается через list_project_groups.
