# Скрытие бокового меню задач

**Status:** done
**Branch:** fix/pomodoro-play-pause
**Worktree:** none
**Goal:** Боковое меню задач полностью скрывается кнопкой; кнопка открытия доступна в шапках задач, календаря и проекта.

## Design
Desktop-состояние принадлежит AppLayout и сохраняется при переходах внутри задач. На других разделах sidebar остаётся видимым. На mobile используется существующая выдвижная панель с явной кнопкой закрытия. AppHeader получает состояние через provide/inject; одинаковое поведение на всех страницах задач.

- Chromium 1280×800: hide/restore, переходы tasks→calendar→project→tasks с сохранением скрытия, header начинается от x=0. Chromium 390×844: кнопки открытия/закрытия панели работают. Ошибок JS нет; API изолирован тестовыми ответами.
