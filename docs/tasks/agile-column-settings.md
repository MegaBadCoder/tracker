# Настройка колонок Agile-проекта

**Status:** done
**Branch:** codex/agile-column-settings
**Worktree:** /Users/v/projects/Alfy/.worktrees/project-sidebar-release
**Goal:** В настройках Agile-проекта пользователь добавляет и переименовывает колонки, меняет порядок и удаляет пустые; удаление колонки с любой задачей отклоняется сервером без потери привязок, изменения видны на доске после перезагрузки.
**Mode:** interactive

## Context
- API колонок уже поддерживает CRUD и порядок; AgileBoardView показывает только заголовки без управления.
- ProjectEditDialog — существующий вход в настройки проекта; пользователь выбрал его вместо кнопки рядом с вкладками.
- Сейчас удаление колонки снимает привязку задач через FK SET NULL.

## Design
В диалоге настроек Agile-проекта отдельный раздел «Колонки»: название каждой колонки с сохранением, кнопки выше/ниже и удаления; внизу форма добавления. Изменения колонок сохраняются сразу, отдельно от общих полей проекта. Загрузка, ошибки и состояние сохранения видимы; повторная отправка блокируется. Удаление требует подтверждения; сервер возвращает 409, если в Agile-колонке есть хотя бы одна задача, включая завершённые и задачи других спринтов. Простые доски сохраняют прежнюю семантику удаления.
Альтернативы: автоматический перенос потребовал бы выбора назначения и массовой записи; запрет удаления занятой колонки проще и выбран пользователем. Отдельная страница настроек не нужна — расширяем существующий диалог.
TDD: yes для серверного API; UI проверяется компонентными сценариями и браузером.

### Invariants
- IV1 — Занятая Agile-колонка и связи всех её задач остаются после отказа удаления; проверка и удаление атомарны.
- IV2 — Все операции ограничены выбранным проектом и правами пользователя; порядок не меняет чужие колонки.
- IV3 — Пустая колонка удаляется; новая появляется в конце; переименование не меняет задачи.
- IV4 — Настройки доступны без активного спринта; ошибка сохраняет введённое значение и допускает повтор; данные одного проекта не попадают в другой.
