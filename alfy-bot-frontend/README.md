# alfy-bot-frontend

Веб-клиент [Alfy](../README.md) — Vue 3 + Vite + TypeScript + Tailwind v4 + Pinia (порт **5173**). Работает в трёх режимах: обычный SPA, Telegram WebApp и устанавливаемое PWA (offline + web-push).

## Возможности

- **Задачи**: Inbox, проекты со списками и board-колонками, повторяющиеся задачи, подзадачи.
- **Колонки Agile-проекта**: в меню проекта «Изменить» → вкладка «Колонки» можно добавить, переименовать, переставить и удалить пустую колонку. Изменения сохраняются сразу. Колонку с задачами (включая завершённые и задачи других спринтов) сервер удалить не позволит — сначала перенесите задачи.
- **Календарь**: недельная сетка с drag-create задач по часам, корректные локаль и первый день недели.
- **Цели и привычки**: создание цели, настройка вопросов-привычек, ежедневные отчёты, аналитика ответов и чарты (`chart.js` / `vue-chartjs`).
- **Pomodoro-таймер** с переносом незавершённых интервалов.
- **PWA**: кастомный service worker (workbox), web-push-подписки, установка на устройство.
- **i18n локали дат**: единый реактивный источник `composables/useLocale.ts` (язык, таймзона, первый день недели — из настроек пользователя).

## Планирование спринтов

Для связей между отдельными задачами используйте [«Зависит от»](#зависимости-задач).

В Agile-проекте откройте **Бэклог → Планирование**: выберите спринт, задайте цель, бюджет и резерв, отметьте задачи или истории и перенесите их одной командой. Выбор истории переносит её незавершённые задачи; ранее выполненные сохраняют назначение. Последний перенос можно отменить, пока он не конфликтует с последующими изменениями. «Предложить план» показывает объяснимый черновик под бюджет; применению предшествует просмотр состава.

Режим **Истории** показывает отдельную доску статусов: проработка, готовность, работа, проверка и выполнение. Названия и порядок настраиваются в «Статусы историй». В карточке истории доступны блокер, зависимости, отложенная дата и архив. Завершение всех задач не закрывает историю автоматически.

На активной доске **Фокус** показывает ближайшие действия, блокеры и загрузку. При завершении спринта можно распределить остаток, записать итоги и улучшение. **Бэклог → Итоги** хранит исходный и итоговый состав; для старых спринтов отмечает неполную историю. Минуты — оценки объёма, а задачи без оценки показаны отдельно.

## Зависимости задач

Чтобы видеть, что мешает начать задачу, откройте её страницу или быстрый просмотр, в блоке **Зависит от** найдите задачу по названию и выберите её. Добавление сохраняется сразу; крестик рядом с задачей удаляет связь. При ошибке остаётся сохранённый набор связей и доступна кнопка повторного сохранения. Например, «Опубликовать демо» зависит от «Свести треки»: пока сведение не выполнено, публикация показывает ожидание.

На карте спринта нажмите значок связей у задачи или **Все связи**. Стрелка идёт от предшественника к зависимой задаче; пунктир отличает её от иерархии. Панель показывает реальные названия: кнопка прицела раскрывает скрытую задачу, ссылка открывает её страницу. Внешние задачи помечены другим спринтом/проектом и не увеличивают прогресс текущего спринта.

Завершение всех предшественников снимает ожидание, но не завершает зависимую задачу. Её можно завершить вручную даже при ожидании. Циклы запрещены; неудачное действие не меняет сохранённые связи. Связи сохраняются при переносе задачи, удаляются вместе с ней и не наследуются следующим повторением автоматически.

## Стек и UI

- Vue 3 `<script setup>` + TS, Vite, Tailwind v4, Pinia, vue-router.
- UI-примитивы — **shadcn-vue** (`style: new-york`, `baseColor: neutral`, иконки lucide) поверх **reka-ui**. Источник истины — [shadcn-vue.com](https://www.shadcn-vue.com/), **не** React-доки. Перед новым компонентом проверь `src/components/ui/`.
- HTTP — axios (`src/api/client.ts`) с JWT-интерцептором и редиректом на `/login` по 401.

## Архитектура — Feature-Sliced Design

```
src/
  features/<name>/{api,lib,model,ui}/   # tasks, calendar, projects, task-timer, goals
  components/ui/                        # shadcn-vue примитивы
  components/                           # общие layout/виджеты (AppLayout, AppHeader, ...)
  views/                               # страницы из router/index.ts
  stores/                              # глобальные Pinia-сторы (user, question-types, navigation)
  api/                                 # общий HTTP-клиент, auth, tokenStorage
  composables/                         # useLocale, useCooldown, usePushSubscription, ...
  mocks/                               # MSW-моки для тестов
  sw.ts                                # кастомный service worker
```

### Drag-and-drop — два независимых стека (не смешивать)

- **Кастомный движок на PointerEvents** (`features/tasks/lib/dnd/`) — reorder задач в Inbox и list-проектах, drop на проекты/Inbox в сайдбаре, drag-create в календаре. Long-press 350ms на mobile, threshold 5px на desktop.
- **vuedraggable** — задачи внутри board-колонок, переупорядочивание колонок.

> **Типы вопросов** грузятся с бэкенда (`GET /api/question-types` через `stores/question-types-store.ts`), не хардкодятся на фронте — иначе бот и веб рассинхронизируются.

```bash
npm install

npm run build               # vue-tsc -b && vite build
npm run preview
npm run generate:pwa-icons
npm run lint                # eslint .

npm run test:run            # vitest run (CI)
```

Тесты — в `tests/` (зеркалят `src/`), env — `happy-dom`, сеть мокается через MSW.

## Конфиг

- `VITE_API_URL` — базовый URL бэкенда (`alfy-bot`, порт 3002). В dev обновляется `scripts/tunnels.sh` при работе через Cloudflare-туннели.
- `VITE_DEV_TELEGRAM_ID` — dev-флаг для авторизации без Telegram WebApp.

Авторизация: `main.ts` пробует `authorize()` при наличии `Telegram.WebApp.initData` или dev-флага. Router guard редиректит на `/login` любой не-public маршрут без токена (`meta: { public: true }` — исключения).

Для переноса проекта удерживайте его название 350 мс, затем двигайте: вправо — вложить под предыдущий проект, влево — поднять уровень, вверх/вниз — выбрать место. Линия и подпись показывают назначение. Escape отменяет перенос. Ветка переносится вместе с потомками; меню «На уровень выше» даёт тот же выход из родителя без drag.
